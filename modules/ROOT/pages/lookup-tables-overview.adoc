= Configuring and Managing Lookup Tables

Lookup tables are centralized reference data used to translate values between systems in Partner Manager mappings. They keep inbound and outbound transformations consistent, reduce repeated mapping logic, and make translation updates easier because table data is managed separately from map definitions.

Use lookup tables when mappings depend on reusable value translation, such as partner-specific codes, internal IDs, or system-specific terminology. This approach improves maintainability, supports bidirectional translation scenarios, and helps scale mapping operations as partner and system values evolve.

== Lookup Table Types

These lookup table types are available:

* *Composite Key Lookup*
+
Use composite key lookup when the result depends on multiple key columns together. This type uses AND logic, so all required key values must be provided for a match.
+
Result: zero or one matching row.

* *Cross-Reference Lookup*
+
Use cross-reference lookup when a row can be identified by any one of multiple key columns. This type uses OR logic across key columns.
+
Result: zero or one matching row.

* *Generic Lookup (optional)*
+
Enable generic lookup when you need flexible filtering by one or more columns and might need multiple matching rows.
+
Result: zero, one, or many matching rows.

== View and Search Lookup Tables

To access lookup tables, select *Lookup Tables* from the Partner Manager sidebar. You can search for a lookup table by name or description and filter by type.

== Lookup Table Limitations

Lookup table limits by environment include:

* Maximum lookup tables: 200
* Maximum columns per table: 10
* Maximum rows per table: 10,000
* Maximum lookup table name length: 50 characters
* Maximum column name length: 30 characters
* Maximum value length per cell: 200 characters

[NOTE]
Each lookup results in an Object Store v2 call. If you anticipate high transaction volume, consider an Object Store v2 premium subscription. For details, see xref:object-store::osv2-usage.adoc[].
